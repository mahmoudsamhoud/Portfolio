The problem

An orbit is only as reliable as its processing.

The original script used a band-stop filter where a band-pass was intended, calculated sampling rate from the final timestamp and offered limited input validation. The supplied files also carried different timestamp precision.

The solution

A complete analysis workflow.

The refined application accepts CSV and Excel, checks timing, exposes filter settings, excludes edge transients and shows raw motion, the filtered band, a central revolution and the spectrum together.

What I built

Engineering calculations made inspectable.

  • Input handling. Worksheet selection, optional CSV headers, finite-value checks and explicit sampling-rate override.
  • Signal processing. Linear detrending and zero-phase Butterworth band-pass filtering with second-order sections.
  • Evidence. Input notes, RMS and peak-to-peak results, numerical tests and cross-file comparison.
  • Outputs. Full-precision processed CSV, a JSON settings report, and PNG/PDF plots.

Measured outcome

Verified against known signals and supplied recordings.

All 12 numerical tests passed. With the verified 6,400 Hz clock, the CSV and Excel filtered outputs agree within 0.0000004 µm. This verifies processing consistency; it does not replace sensor calibration or establish a machinery diagnosis.
