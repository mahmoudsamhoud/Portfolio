One design basis, connected outputs

Storage-tank design involves related decisions about geometry, liquid levels, materials, loads, plate thicknesses and structural details. This tool connects those inputs to a calculation summary, a detailed report, a data sheet and a general-arrangement sketch.

Developed by Eng. Hesham Fouad and Eng. Mahmoud Samhoud, Static Equipment Engineers, Pressure Vessels Department – ENPPI, as credited in the supplied application.

The supplied revision identifies its calculation basis as API 650, 13th Edition, March 2020. This project page describes the implementation; it does not certify code compliance.

A guided engineering workflow

  1. Establish the project

    Enter document identifiers and engineering metadata, choose SI or US Customary units, or use the ITSdesign report reader to populate supported inputs.

  2. Define the tank

    Set dimensions, shell courses, liquid levels, specific gravity, pressures, temperature, material family, roof arrangement and environmental loads.

  3. Develop the details

    Configure bottom plates, compression-ring details, roof supports, stiffening rings, anchorage and nozzles.

  4. Review calculations and notes

    Inspect required versus provided values, clause references, check status and applicability notes. Review failures before exporting results.

  5. Prepare deliverables

    Generate the sketch, review the calculation report and data sheet, then save project data or export the required output.

Available settings depend on the selected tank configuration. The source includes notes and checks for combinations outside the implemented method’s scope.

Reports and drawings from the same inputs

  • Calculation report. Project title block, engineering sections, equations, clause references, check status and design notes, with browser print/PDF output.
  • Data sheet. HTML and Excel outputs, including a tank sketch.
  • General arrangement. Elevation, plan, liquid levels, internals, stair arrangement, nozzle schedule and compression-ring detail, controlled through drawing settings.
  • Drawing exports. SVG, PNG, DXF and an AutoCAD 2000 DWG writer are implemented in the supplied file.
  • Project continuity. Save/open controls, browser-local persistence and migration logic for older saved states.

A portable browser application

The application is packaged in one HTML file with embedded styling, JavaScript and supporting library code. No external script or stylesheet tags are required by the supplied file.

The source separates material and calculation functions, sketch geometry and export writers, report generation, input schemas, and interface state. The seven main tabs are General Information, Design Data, Tank Configuration, Tank Design, Shell Nozzle Reinforcement, Tank Sketch and Print Preview.

This portfolio includes an unchanged copy of Rev.03. The report describes the tool without reproducing its full source.

Review status and engineering use

Portfolio integration checks cover the copied file, JavaScript syntax and local page links. They do not independently validate the engineering formulas, exported drawings or every configuration.

The application itself states that results need independent verification before use on project deliverables. Its stated scope does not include other code editions, API 653 or API 620; a method or edition should not be inferred from the availability of an import reader.
