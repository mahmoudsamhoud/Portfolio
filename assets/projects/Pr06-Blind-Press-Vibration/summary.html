Input and approach

The input BlindPressData.txt appears in Circular Plot + Vip_Analysis + Waterfall. SHA-256 comparison confirmed identical copies; these analyses are grouped in one project and the repository stores one canonical recording. The press and bearing recordings have different contents, so each receives its own repository even though their analysis methods overlap.

Measured results

The strongest non-DC X-channel bin is 9.998 Hz. True RMS is 3.1815 and peak-to-peak is 20.6142, both in recorded units. The default-band envelope spectrum peaks at 3.191 Hz. The time–frequency analysis uses 15 overlapping windows, with 8.000 Hz bin spacing.

Validation

13 numerical checks passed, plus a completed run on the supplied recording. Source and input provenance stay with the independent repository.

Interpretation

Amplitude calibration, confirmed machine metadata and bearing geometry are not supplied. All amplitudes are in recorded units. The 100–500 Hz envelope band is inherited from the original scripts and remains an exploratory choice. A spectral peak, an elevated crest factor or the name outerfaultdata.txt alone does not establish a bearing fault. Waterfall windows trade frequency resolution for time resolution; their bin spacing differs from the full-record FFT.
